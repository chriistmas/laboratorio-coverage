# Laboratorio 04: xUnit y Cobertura de Código

Este repositorio contiene la implementación práctica del algoritmo **Bubble Sort** y su suite de pruebas unitarias utilizando **JUnit 5** y **JaCoCo** para la medición de la cobertura de código.

## Integrante
* **Nombre:** Ronald Reynaldo Valdez Agüero

## Tecnologías Utilizadas
* **Lenguaje:** Java 21 (OpenJDK)
* **Gestor de dependencias:** Apache Maven 3.8.7
* **Framework de pruebas:** JUnit 5 (Jupiter)
* **Herramienta de cobertura:** JaCoCo

## Instrucciones para ejecutar las pruebas y generar reportes

Para compilar el proyecto y ejecutar la suite de pruebas automatizadas, ejecute:
```bash
mvn clean test
```

El reporte interactivo de cobertura se generará en la siguiente ruta:
`target/site/jacoco/index.html`
